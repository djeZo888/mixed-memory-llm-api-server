## Pins are reproducibility baselines

V1 used native Codex `0.158.0`, upstream `064c6b8c737f5b41d171fdda80bd9ef10ad06eb3`, configured context `480000`, automatic compaction threshold `400000`, and output ceiling `65536`. The last intended placement had two Qwen general instances, one MiMo general instance, Qwen3.5-9B plus PaddleOCR-VL-1.6 for reading, and Qwen-Image-2.1 for generation/editing. The final session did not accept all six operating together or full occupied context.

These model/configuration/source/runtime pins explain old evidence. They are **V1 baselines, not automatic V2 mandates**. V2 must explicitly select compatible versions and limits, retain provenance and licenses, and qualify its supported workload. Do not silently carry over old boot IDs, owner records, qualifications or runtime state. Protect reusable assets and user data while reviewing them; do not expose secret material in the new repository.
