successful hybrid runtime memory envelope above. The harness promotion also
needed its install/verification order corrected. Repeated handoff and exact
deployment-review steps added overhead; these orchestration costs contributed
to the incomplete result. A future round should run the complete native parser,
application, hybrid-selection and writable-cache preflight before weight
loading, and avoid approval roundtrips for bounded task metadata corrections.
