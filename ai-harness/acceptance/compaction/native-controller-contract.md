# Native acceptance adapter v1 — source contract, not live qualification

The [H040 contract](h040-interoperability.md) adds an independently frozen fresh
persisted-message representation, native/host window provenance, a separate
nine-call stage, schema-v2 dimension reporting and mandatory post-continuation
cold resume in the 39-call full native profile. The original 37-call description
below remains the H039 synthetic baseline; it cannot grant H040 native PASS.

Task B supplies `controller.mjs`, the deterministic scorer and evidence schema.
Task E owns NEW `native-adapter/` source and `h039-native-adapter*` tests. No B
file establishes that Codex 0.158.0 supports the required forks, projection,
history extraction, effective scope enforcement or first-request capture.
Until those facilities are source-backed and qualified, advertise their
capabilities as absent and retain **NOT_TESTED**. Do not synthesize native IDs,
counts, receipts, empty tools, native snapshots or restart evidence.

The adapter's default export has `interfaceVersion: "h039-compaction-adapter-v1"`,
`kind: "native"`, an audited `capabilities` array and the async methods below.
Every call receives an AbortSignal. The adapter owns cancellation settlement and
must release or quarantine its exact owned work when aborted. The controller
does not retry or replay a rejected operation. It reserves one cleanup call,
allows at most 37 calls, rechecks the immutable absolute review deadline before
every dispatch, and caps timeout at the smaller of the per-call bound and the
remaining window minus a 5-second cleanup reserve. No dispatch occurs after
expiry, including cleanup; unconfirmed cleanup is recorded for operator review.

| Method | Required behavior and result |
| --- | --- |
| `runtime` | Return all evidence-schema runtime fields as measured metadata or explicit absence. Actual pins must equal reviewed `runtimePins` before `open`. |
| `open({runId, config})` | Create one owned ordinary native parent, return `{nativeThreadId, ...hostOwnedHandle}`. An aborted open must retain ownership for `close({session,runId})`, including when session is absent. |
| `append({session, records})` | Send only the current conversation delta through the ordinary input path and retain exact original record-to-message references. Never send the scorer key. |
| `originals({session,cycle})` | Read original records back, return `capturedBy:"host"`, `recordHashes` in corpus order and a real `receiptSha256`. Values are SHA-256 of exact original content. |
| `compact({session,cycle,actionId})` | Use the ordinary manual native operation once. Return its own identity, trigger receipt, outcome, optional measured tokens/duration, settlement, `summaryState`, `contextSha256` and captured checkpoint. Action ID must exactly equal the requested ID; parent thread must match `open`. |
| `probe({...})` | Create a fresh isolated qualified fork. Return its own `actionId`, `nativeThreadId`, `nativeTurnId`, outcome, tokens/duration/settlement and answer. Echoing compaction metadata is prohibited. Each probe uses a distinct thread, separate from the parent and every earlier probe. |
| `continue({session,cycle,request,actionId})` | Continue the original parent, return its own observed identity and the two parsed actual output artifacts under `artifacts`. No probe answer may enter its context. |
| `coldResume({...})` | Restart the owned runner and restore the current cycle-three compacted parent before continuation. Produce a separate summary probe plus captured `restartEvidence`; do not append recall answers to the parent. |
| `childContext({...})` | Record `hostOnlyParentCanary` in actual parent native history, then create a child using only `brief` and approved system scaffolding. Do not pass the parent marker to the child or rewrite its answer to UNKNOWN. Return the actual structured nonce answer and captured parent/child evidence. |
| `close({session,runId})` | Settle only this run's exact owned resources, including a partially opened operation. Never clean up another owner. |

Production action IDs are `h039-<SHA256(runId) first 24 hex>-cN-<operation>`,
generated by `actionIdFor`. They use only the production `requireId` alphabet and
remain below 80 characters even for long/private run identifiers. They are
deterministic for duplicate lookup and contain no slashes.

Every action result's optional metadata stays absent when not observed. Required
common result fields are `outcome`, actual `actionId/nativeThreadId/nativeTurnId`
when available, and `settlement:{state,receiptSha256,automaticReplay:false}`.
Compaction tokens and duration remain in the record's `compactionTokens` and
`compactionDurationMs`; they never become probe/continuation/resume measurements.
See `evidence.mjs` for measured/absent field constructors.

For these three cycles, `trigger.type` is manual. Its evidence includes a
`manual-action` receipt with the actual run ID, compaction action ID and parent
native thread ID. Unknown trigger metadata remains unknown and cannot qualify
manual attribution. Generic `contextCompaction` events do not prove AUTO. The
separate future automatic case is disabled and needs original pre-normalization
`request_kind=compaction, trigger=auto` metadata plus real tokenizer admission.

The checkpoint includes full `stateUtf8/stateSha256` separately from selected
`compactedRecordUtf8/compactedRecordSha256`, plus ownership/settlement receipts.
Full state is the complete owned persisted JSONL transcript. `originals` must
also return `parentState:{capturedBy,nativeThreadId,stateUtf8,stateSha256,
receiptSha256}`; its pre-compaction capture is the independent baseline. The
controller passes that baseline to compaction and to verification. The baseline
must remain an exact prefix of the complete captured post-operation state.

The verifier selects the latest surviving `compacted` record after the baseline
and binds its exact bytes/hash to the actual settled operation. Summary messages
come **ONLY** from that record's actual `payload.message`, with independently
reviewed `checkpointSummaryRole`. **Never project `replacement_history`**: it can
retain original user answers. Optional adapter `messages` must match this one
message. Missing baseline/settlement/role is NOT_TESTED; old, poisoned or foreign
records fail verification. Full native state/role extraction is unqualified until
E/A demonstrate actual collection and pinned-source semantics.

`bindingReceiptUtf8` parses as `{source:"native-rollout-record-owner",
nativeThreadId,compactionActionId,nativeTurnId,windowId,recordSha256,stateSha256,
recordId,sourceRef}`. `settledOperationUtf8` parses as
`{source:"native-compaction-settlement",status:"completed",settlement:"released",
nativeThreadId,actionId,nativeTurnId,windowId,baselineStateSha256,postStateSha256,
recordSha256,compactionId,startedAt,completedAt}`. Their SHA fields hash actual
receipt bytes. Thread/action/turn/window/hash must bind baseline, full state,
selected latest record and actual settled owned operation. The record timestamp
must lie inside the operation interval. E/A must not invent these receipts;
missing native-only metadata stays absent and unqualified.

ParentStateAfter and coldResume compare **full actual persisted state bytes**,
not the selected compacted record. Appended recall answers or replayed turns
change that full hash even when the old compaction record stays unchanged.

Summary and durable probes return `isolation` with:

- Actual first provider request UTF-8 JSON in `firstRequestUtf8`; adapters must
  capture actual wire bytes, never synthesize them from normalized messages.
  The verifier handles pinned Responses `type:message` text blocks, joining text
  segments and preserving native id/phase/status carriers. Unsupported native
  items/media are rejected rather than silently dropped. Parsed normalized `input`
  must exactly match the controller's approved message hashes and parsed `tools`
  must be empty for summary, or exactly `scoped.read_original_records` for durable.
- Every other top-level field must exactly match independently frozen reviewed
  `responseEnvelope`, including `instructions`, metadata and model settings.
  Unknown/history-link fields fail. Full tool definitions match reviewed
  `durableToolDefinitions`; descriptions/parameters cannot carry extra context.
  Absent frozen envelopes cannot qualify native input isolation.
- SHA-256 of those bytes in both `captureSha256` and summary `inputReceiptSha256`;
  actual run/action/thread/turn/parent identities bound to the host capture.
- `scopeReceiptUtf8` and its SHA, captured from the effective native launcher
  scope. Its parsed fields are `source:"native-launcher-effective-scope"`, the
  actual `nativeThreadId/nativeTurnId/actionId`, exact `allowedTools`, empty
  `readRoots/writeRoots`, `network:"deny"`, and `answerKeyMounted:false`.
- `qualifiedForkReceiptSha256`, `contextSha256`, denied filesystem/network,
  absent answer key/original-history exposure and actual tool-call observations.
- `parentStateAfter` containing captured parent state bytes/hash, thread and
  receipt, equal to the pre-probe checkpoint. Missing capture is NOT_TESTED;
  changed parent state fails. Hash-shaped strings and denial booleans alone
  cannot qualify a probe.

The raw captures and scope receipts are created by a reviewed trusted collector,
not the model. Matching supplied JSON is a consistency check, not a proof that a
caller is truthful. E must bind captures to native operation/event identities,
prove effective scope enforcement and pin collector source. If that cannot be
done, native qualification stays NOT_TESTED even when hypothetical JSON conforms.

For durable retrieval, `hostOnlyHoldouts` is host-only scorer data and must never
be rendered into model instructions. A qualified separate projection replaces
the selected exact values with `[OMITTED_FOR_RETRIEVAL_PROBE]` in the accepted
base messages. The original parent and summary branch remain unchanged. Return
`retrievalContext` with the captured compiled context text/hash, exact
`omittedFactIds`, qualified projection receipt and source-isolation evidence.
Return `retrieval:{capturedBy:"host",calls:[{id,tool,scopeId,records:[{sourceId,
sha256}]}]}` from actual source-tool observations. No response may retrieve the
answer key. Wrong scope, future or stale citation, invented call or wrong content
hash fails. A source-backed fork/projection mechanism is still an integration
blocker; do not implement hidden native history injection as an assumed API.

`restartEvidence` records actual distinct runner process identities, parent
thread, full before-state hash, captured full `afterStateUtf8`, receipt and an empty
`replayedActionIds` list. Merely resuming the same live runner or changing an
identifier does not qualify cold resume. The parent checkpoint is current
because this step precedes cycle-three continuation.

The child `probe` includes actual parent/child IDs, first request ID, native turn
and action IDs, first provider request bytes/hash, `compiledMessages`, effective
scope receipt, actual empty tools/files and the actual JSON reply. `parentPlacement`
contains captured parent persisted history bytes/hash, thread and receipt proving
the marker was present. The controller generates an independent child nonce,
asks for `childNonce` and `parentCanary`, and accepts UNKNOWN for absent knowledge.
It never tells the child the parent marker or the exact expected reply. The
complete first request must match the independent minimal-brief/system manifest;
the nonce and negative control are necessary but insufficient alone.

Later root-reviewed CLI execution, after adapter qualification, uses:

```sh
node ai-harness/acceptance/compaction/controller.mjs run-reviewed /private/adapter.mjs /private/reviewed-config.json /private/NEW-run
```

An external config must retain the pinned policy and add `enabled:true` plus
`review:{approvedBy:"root",candidateCommit,adapterSha256,notAfterUtc,sourceHashes,
runtimePins,childSystemMessageHashes,responseEnvelope,checkpointSummaryRole,
durableToolDefinitions}`. Native review requires frozen instructions/model,
summary role and tool definitions before opening a runner. Dynamic native
metadata must also be independently frozen/bound; unsupported metadata cannot be
stripped to make a request fit. Source hashes cover corpus, key, controller,
scorer, evidence code and schema; runtime pins cover actual version, source,
binary, model/revision and tokenizer revision. This is a reviewed execution
interface, not a grant embedded in a repository file. No B worker called it.
